Design

不做 SaaS，做一本手账。

「家常手账 · 拾光」是栖迟的设计立场：纸白、墨色与赤陶，一像素细线，衬线标题。没有渐变、霓虹和彩色阴影，也不把每个区块都套进卡片里。

01

纸面感

平面、暖白底、1px 细线。层级靠留白与线，不靠 elevation 和投影。

02

手账感

日期印章、小票明细、勾选纸、日记式时间轴——细节都从日常生活里来。

03

克制

主色只用于操作、选中与链接，整页占比不超过一成；一屏只有一个视觉重点。

Get started

自己家的服务器，
自己家的数据。

不需要域名、不需要备案，也不用把照片交给任何云服务。一台常开的小主机，一部手机，就可以开始。

01

起一台服务器

需要 PocketBase 0.40+。把 pb_migrations/ 与 pb_hooks/ 放进项目根目录，docker compose up -d 就能启动。

02

让家人连上来

首次打开 App，填写 局域网IP:8090 并注册。第一个注册的账号会自动成为管理员。

03

开始记事、点菜

四个模块共享同一套数据。Android 手机装 APK，Windows 装桌面版；没网也能用，联网后自动同步。

Quick start · shell 
# 后端：PocketBase 0.40+
docker compose up -d

# 客户端：Flutter
flutter pub get
flutter run -d windows

Questions

一些常被问到的事。

如果你也在找一个「数据不离开家」的家庭工具，下面这几条大概能帮你判断它是否合适。

一定要有公网或云服务器吗？

不需要。整套系统只在你家局域网里跑，出门在外连不上，也不会把生活数据传到任何第三方。AI 导入需要调用 DeepSeek，是否配置由你决定。

支持哪些设备？

Android 手机（APK 侧载，minSdk 23）与 Windows 10/11 桌面版。目前不做 Web 与 iOS——浏览器扫不到局域网设备，手机端也以原生体验为先。

AI 功能必须配置吗？

可选。管理员在「家庭 → AI 设置」里填入 DeepSeek API Key 后，可以用文本、链接或图片导入食谱；不配置也能完整使用其他功能。

数据存在哪里？

后端数据在自家的 PocketBase（SQLite）里，由那台小主机保管。客户端有本地缓存，离线也能记录与浏览，联网后按队列自动同步。

可以给别的家庭用吗？

目前定位是「一个家庭、一台服务器」：不做多租户、不做支付、不接公网。代码开源，可以按自己家的习惯改。
